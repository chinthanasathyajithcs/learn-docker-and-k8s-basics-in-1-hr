Sam's Burger Stall

Four helpers, each in its own container: the cashier (this page, FastAPI), the filing cabinet (PostgreSQL), the bell (RabbitMQ) and the notebook. Docker Compose starts them together.

Quick Links

  • Health: /healthz
  • Place an order (POST): /orders
  • List orders (GET): /orders
  • The bell (RabbitMQ UI): http://localhost:15672

Try It

Example command:

curl -X POST http://localhost:9000/orders -H "Content-Type: application/json" -d '{"id":1001,"item":"Cheeseburger","status":"NEW"}'

The cashier creates the RabbitMQ queue orders and binds it to stall.events on startup. Open the RabbitMQ UI and use Get messages. No queue setup in the UI is required.
