This is the IFS Work Order API – Classroom Demo for NSBM

This demo mirrors an IFS-style microservice: API + Postgres + RabbitMQ, with ELK (Elasticsearch, Logstash, Kibana) for logs. Containerized with Docker.

Quick Links

  • Health: /healthz
  • Create Work Order (POST): /workorders
  • List Work Orders (GET): /workorders
  • RabbitMQ UI: http://localhost:15672
  • Kibana: http://localhost:5601 (data view nsbm-logs-*)

Try It

Example command:

curl -X POST http://localhost:9000/workorders -H "Content-Type: application/json" -d '{"id":1001,"title":"Replace pump seal","status":"NEW"}'

The API creates the RabbitMQ queue workorders and binds it to ifs.events on startup. Open the RabbitMQ UI and use Get messages. No queue setup in the UI is required.
